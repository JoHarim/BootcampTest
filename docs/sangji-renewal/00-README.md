## 시안 직접 보기
```bash
pnpm install
pnpm dev          # 브라우저에서 http://localhost:3000/sangji
```
- 화면 7종: `/sangji`(홈) · `/sangji/products`(제품 검색) · `/sangji/products/TC%2035-52-8`(상세) · `/sangji/solutions`(산업별 솔루션) · `/sangji/resources`(기술자료) · `/sangji/about`(회사소개) · `/sangji/quote`(온라인 견적)
- 화면의 품번·가격·재고·연혁은 **예시 데이터**다 (`apps/web/lib/sangji/catalog.ts`). 회사명·주소·전화·취급 품목·설립연도는 현 홈페이지 공개 정보 기준.

## 전제 (읽기 전에)
- 이 세션의 네트워크 정책상 현 홈페이지(sangjiintl.co.kr)와 벤치마크 3개 사이트에 직접 접속하지 못했다. 현 홈페이지 정보는 검색엔진에 잡힌 공개 페이지(회사소개·대리점·패킹·타이밍벨트·FPC·자료실 등)와 메뉴 구조로 재구성했다. **로고·사진·색상 등 실제 그래픽 자산은 반영하지 못했고**, 시안은 "구조와 기능"을 보여주는 것이다. 자산을 받으면 그대로 입힐 수 있게 색·글꼴은 한 파일(`sangji.css`)에 토큰으로 모아 두었다.
- 견적은 2026년 국내 에이전시 공개 단가 범위와 항목별 공수 추정으로 산출한 **범위 견적**이다. SKU 수·규격 데이터 보유 형태·고도몰 커스텀 현황 등을 확인하면 확정 견적으로 좁힐 수 있다 (제안서 9장 질문 목록).

## 결정 기록
- **2026-09-07 시안을 정적 HTML 이 아니라 Next.js 라우트(`/sangji`)로 제작** — 이유: 검색·필터·견적 폼이 "실제로 눌러지는" 시안이어야 B2B 담당자가 검색 UX 를 판단할 수 있고, 방안 2(신규 구축)를 택하면 이 코드가 그대로 출발점이 된다. 버린 대안: 이미지 시안(피그마)·정적 HTML. 영향: `apps/web/app/sangji/*`, `components/sangji/*`, `lib/sangji/catalog.ts` 추가. 기존 게임(`/`)·사주(`/saju`)·RPG(`/rpg`) 라우트는 손대지 않음.
- **plan.md 는 아직 이 프로젝트로 바꾸지 않음** — 방안이 확정되기 전이라 조립 순서를 못 정한다. 방안이 정해지면 `기획하자`(blueprint) 로 plan.md 를 이 프로젝트용으로 새로 채운다.
